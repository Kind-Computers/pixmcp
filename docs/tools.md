## csv

### pix_csv_compare

**Compare Unreal CSVs** · read-only · cost `job`

Compares recorded UE CsvProfiler GPU pass timings using optional pixdiff. Returns a job and a complete saved comparison: positive candidate-minus-baseline milliseconds mean the candidate is slower. Recorded CSV aggregates remain separate from PIX replay timings. Read /items or /missing with pix_result_read; follow a pass using pix_csv_pass_candidates.

| Parameter | Type | Default | Description |
|---|---|---|---|
| `baselinePath` | string | required | Path of the baseline Unreal CSV file. |
| `candidatePath` | string | required | Path of the candidate Unreal CSV file. |
| `prefix` | string | `"GPU/"` | GPU timing column prefix, default GPU/. Selected columns must contain milliseconds. |
| `stat` | string | `"median"` | mean, median, or p95. Median is the tutorial's two-GPU default. One of `mean`, `median`, `p95`. |
| `timeoutSeconds` | integer | `120` | Process timeout in seconds, 1 through 3600. Default: 120. Range 1..3600. |
| `waitSeconds` | number | `0` | Seconds to wait inline for the job to finish before returning (default 0 = return the job immediately; poll pix_job_status or block with pix_job_wait). Range 0..3600. |

Output: `jobId`, `kind`, `description`, `status`, `progress`, `createdAt`, `startedAt`, `finishedAt`, `elapsedSeconds`, `messages`, `error`, `resultRef`, `cancellationRequested`, `nextCalls`, `resultState`, `resultError`, `origin`, `partialResultRef` | or | `deferred`, `resultRef`, `totalBytes`, `nextCalls` | or | `code`, `message`, `hresult`, `retryable`, `nextCalls`

### pix_csv_pass_candidates

**CSV pass marker candidates** · read-only · cost `query`

Finds candidate PIX markers for an exact passName in a saved CSV comparison. Searches the caller-selected GPU capture by name after removing the CSV prefix; exact names precede substring matches. All results are name-based candidates, including duplicates, and do not prove that the capture corresponds to either CSV. Pages reuse saved comparison data without reading the CSV files or replaying.

| Parameter | Type | Default | Description |
|---|---|---|---|
| `resultRef` | string | required | The resultRef of a finished pix_csv_compare job. |
| `passName` | string | required | CSV pass (stat) name whose PIX marker candidates are wanted. |
| `handle` | string | required | GPU capture handle whose markers are searched. |
| `offset` | integer | `0` | First item to return (default 0). Range 0... |
| `limit` | integer | `25` | Maximum items to return (default 25, max 1000). Range 1..1000. |

Output: `resultRef`, `passName`, `handle`, `searchText`, `evidence`, `identityEstablished`, `pass`, `total`, `offset`, `count`, `nextOffset`, `items`, `unavailableReason`, `nextCalls` | or | `deferred`, `resultRef`, `totalBytes`, `nextCalls` | or | `code`, `message`, `hresult`, `retryable`, `nextCalls`

### pix_device_d3d_settings_set

**Set D3D setting** · idempotent · cost `query`

Changes one D3D setting for processes launched afterwards through this connection (does not affect running processes). category: debugLayer, dred or device. setting: a name from pix_device_d3d_settings, e.g. AUTO_BREADCRUMBS, PAGE_FAULTS, RETAIN_DUMP_FILE, FORCE_WARP, MODE. value: true/false for enable settings; an option name (APP_CONTROLLED, FORCE_ON, FORCE_OFF; for DRED enablement SYSTEM_CONTROLLED, FORCED_ON, FORCED_OFF) for option settings; a number for percentages; a feature level (D3D_FEATURE_LEVEL_12_0) or comma-separated flag names (MEDIUM_OVERHEAD,EVENT_MARKERS) where applicable. To make a GPU hang produce a dump for pix_dump_open: set dred AUTO_BREADCRUMBS and PAGE_FAULTS to FORCED_ON and device RETAIN_DUMP_FILE to true, then pix_device_launch with flags [GPU_CAPTURE_ENABLE_DRED_LOGGING].

| Parameter | Type | Default | Description |
|---|---|---|---|
| `handle` | string | required | Device handle |
| `category` | string | required | debugLayer, dred or device One of `debugLayer`, `dred`, `device`. |
| `setting` | string | required | Setting name, e.g. AUTO_BREADCRUMBS (see pix_device_d3d_settings). |
| `value` | string | required | New value: true/false, an option or enum name, a number, or comma-separated flag names depending on the setting type. |

Output: `changed`, `category`, `result` | or | `deferred`, `resultRef`, `totalBytes`, `nextCalls` | or | `code`, `message`, `hresult`, `retryable`, `nextCalls`
